# Result tables

The files in this directory are generated by the final scripts and retained for auditability.

## Locked test

- `locked_test_model_comparison.csv`: primary 100-minute cohort, all models and metrics.
- `locked_test_sensitivity_model_comparison.csv`: 500-minute cohort.
- `locked_test_cohort_audit.csv`: row, recipient, season, and winner retention counts.
- `locked_test_winner_audit.csv`: actual winner, predicted leader, winner rank, and NDCG by model-season.
- `locked_test_top5_predictions.csv`: top-five candidate lists for the three serious learned models.
- `locked_test_success_criteria.csv`: six prespecified decision criteria.
- `locked_test_guardrails.csv`: chronological and leakage controls.
- `locked_test_champion_sensitivity.csv`: direct 100- versus 500-minute champion comparison.

## Data and deployment audits

- `source_schema_audit.json` and `original_schema_audit.json`: source compatibility and data-quality reports.
- `deployment/`: 2022 shadow-deployment predictions, feature drift, monitoring results, contract, and figures.

PNG copies in the root of this directory are regenerated by `src/locked_test_evaluation.py`. Curated publication versions are under `reports/figures/`.
